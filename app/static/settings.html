Settings

The Pi's clock, the Wi-Fi it hosts, and what is stored.

Clock

Every reading is stamped with the Pi's time. The Pi keeps time with a small battery-backed clock, because it has no internet to ask. Set it once, and again after replacing that battery.

The clock can't be trusted right now. Readings are held in memory (0 so far) and saved with the right times once you set the clock.

Electricity cost

Give energy a price and the dashboard shows what each plug costs, next to its power and energy. Prices can differ by time of day, for example a cheaper night rate.

Used whenever no time slot below applies.
Slots follow the clock in this zone, daylight saving included.

Time slots

Optional. Each slot has its own price for the days and hours you choose. If slots overlap, the one higher in the list wins. Times use 15-minute steps. A slot that ends before it starts runs past midnight into the next morning, so 23:00 to 07:00 ticked for Mon to Fri covers the mornings of Tue to Sat. Start and end equal means the whole day.

Week at a glance

    Costs are worked out from the readings and today's prices, so changing a price changes the cost shown for past days as well.

    Wi-Fi for the plugs

    The plugs join this network, so the Pi has to be on it too: connect the Pi to the router with a cable. It finds the plugs by their names, so nothing here needs internet. In your router, reserve each plug's address so it never changes.

    Secure connection (HTTPS)

    With HTTPS the dashboard password and everything you do here travel encrypted. The Pi makes its own certificate, so it needs no internet, no domain name and no renewing by hand. In return each device you use has to trust the Pi's certificate authority once.

    The certificate is valid for about 13 months. The Pi checks it every few minutes and makes a new one by itself when it is close to expiring or when its network address changes. It only needs the Pi's clock to be right.

    1. Trust this Pi on each device

    Download the certificate authority

    Fingerprint to compare when the device asks: –

    Windows

    Open the downloaded file, choose Install Certificate, then Current User. Pick Place all certificates in the following store, choose Trusted Root Certification Authorities, and finish. Restart the browser. Chrome and Edge then trust it.

    macOS

    Open the file. Keychain Access adds it. Double-click it there, open Trust, and set When using this certificate to Always Trust. Close and enter your password.

    iPhone and iPad

    Open this page in Safari on the device, tap Download, and allow it. Then open Settings, tap Profile Downloaded and install it. After that go to Settings, General, About, Certificate Trust Settings and switch on full trust for it.

    Android

    Download the file, then open Settings, Security (on some phones Security and privacy, More security settings), Install a certificate, CA certificate, and choose the file. Android warns that the network may be monitored: that is its standard message for any added authority.

    Linux and Firefox

    Firefox keeps its own list: Settings, Privacy and Security, View Certificates, Authorities, Import, and tick Trust this CA to identify websites. For the rest of the system on Fedora copy the file to /etc/pki/ca-trust/source/anchors/ and run sudo update-ca-trust; on Debian or Ubuntu copy it to /usr/local/share/ca-certificates/ and run sudo update-ca-certificates.

    Backup and restore

    One file holds everything: your plugs, all their readings, the electricity prices, the address each plug keeps and the settings. Keep a copy somewhere other than the SD card, for example before updating the Pi or after changing plugs.

    Download a backup

    The file is named with the date and time, like shelly-pi_2026-10-17_03-53-00_v0.1.5.zip (the last part is the app version that made it).

    It doesn't contain the dashboard or Wi-Fi password.

    Restore from a backup

    This replaces everything stored on this Pi with what is in : plugs, readings, prices, plug addresses and the polling and storage settings. The current data is first copied aside on the Pi, so a mistake can still be undone by hand. This Pi's Wi-Fi name and password, the dashboard password and the network address are kept.

    Power

    Shut the Pi down before unplugging it or adding hardware, so the SD card and the readings are saved properly. Readings are not taken while it is off.

    Update the app

    Running version –. The Pi has no internet, so this device does the downloading: look for a new version, save the file it offers, then send that file to the Pi here. Your data is kept. If the new version doesn't start, the Pi goes back to the old one by itself.

    Automatic backups to a USB drive

    Plug a USB stick or drive into the Pi and it saves a backup there on a schedule, so a copy always exists apart from the SD card. Nothing on the drive is changed or formatted: backups go into a folder called shelly-pi-backups, and the Pi only ever deletes its own older backups from that folder. The drive is used just while a backup is copied, so you can unplug it at any other time.

    Only drives plugged in right now are listed. Needs exFAT, FAT32, NTFS or ext4.

    Recent backups are kept close together and older ones further apart: about one every hour, 2 hours, 4 hours, 8 hours, then every day, 2 days, 4 days, 8 days, 16 days, month, 2 months, 4 months and so on, up to 2 years. That is around 30 files, however often you back up. The Pi decides this by the time in each file name, and only touches files named like its own backups.

    The time of day and the date in each file name follow this zone.
